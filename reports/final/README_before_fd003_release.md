# Jet Engine Hospital

A multi-task early-warning and predictive-maintenance system for NASA C-MAPSS turbofan engines.

## Course Information

- Course: Machine Learning
- University: Shahid Beheshti University
- Instructor: Dr. Farahani
- Term: Spring 2026

## Main Objectives

1. Remaining Useful Life estimation
2. Failure risk within 10, 20, and 30 cycles
3. Unsupervised anomaly detection
4. Maintenance recommendation: CONTINUE, INSPECT, or STOP

## Project Stages

- Stage 1: FD001
- Stage 2: FD003
- Optional Bonus: FD004

## Repository Structure

- data/: raw, interim, processed, and split data
- notebooks/: main project notebook
- src/: reusable Python modules
- artifacts/: models, preprocessors, calibrators, and metadata
- app/: Streamlit dashboard
- reports/: figures, tables, and final report
- scripts/: training and export scripts
- tests/: split, leakage, and causality tests
